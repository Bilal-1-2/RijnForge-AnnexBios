# AnnexBios Leidscherijn

AnnexBios Leidscherijn is a PHP-based cinema website that provides users with information about current and upcoming films, allows ticket booking, and integrates with an external API for movie data. The website features a film agenda, detailed film pages, and a booking system with seat selection.

## Features

- Display of films with posters, titles, ratings, release dates, and detailed information.
- Film filtering by genre, date, and category.
- Integration with an external API to fetch movie data, showtimes, and ticket orders.
- Booking system with seat selection.
- Responsive design for optimal viewing on various devices.
- Accessibility information and company contact details.
- Multiple cinema locations with maps and images.

## Installation

1. Clone or download the repository to your local server environment (e.g., XAMPP).
2. Ensure PHP and cURL are enabled on your server.
3. Place the project files in your web server's root directory (e.g., `htdocs` for XAMPP).
4. Access the website via your browser at `http://localhost/AnnexBios` or your configured local URL.

## Usage

- Navigate to the homepage to view featured films and company information.
- Use the film agenda to browse films by category or date.
- Click on a film poster or "Meer info & tickets" button to view detailed information and book tickets.
- Use the booking page to select seats and complete your ticket purchase.

## Technologies

- PHP for server-side scripting and API integration.
- HTML5 and CSS3 for markup and styling.
- JavaScript for interactive elements and filtering.
- cURL for API requests.
- External API for movie data and ticket orders.
